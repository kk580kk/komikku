# 演示脚本（5 分钟走完 P0）

用于向上演示或验收。前置：已签名 HAP 装到真机，网络可用。

## 1. 首屏与书架（30s）

- 冷启动 → 书架 6 本种子漫画，封面为渐变占位（种子无真实封面）
- 顶部搜索框输入「芙莉莲」→ 只剩 1 本；清空恢复
- 说明：未读角标来自 SQL 子查询，不是前端算的

## 2. 浏览与加入书架（90s）

- 切到「浏览」→ 自动加载 MangaDex 热门（真实封面）
- 搜索「One Piece」→ 列表刷新
- 点任一结果的「加入」→ toast「已加入书架」→ 切回书架可见该条目（真实封面）

## 3. 详情与阅读（120s）

- 点新加入的条目 → 详情页：封面/作者/简介/章节列表
- 点某章 → 阅读器：长条滚动、页码、双击放大、双指缩放
- 返回详情 → 该章置灰（已读）
- 重进同一章 → 回到上次页码

## 4. 下载与离线（90s）

- 阅读器点「下载」→ 顶部进度递增 → 完成提示
- 打开飞行模式 → 重进该章 → 仍可阅读（走本地文件）
- 设置页 → 下载内容有占用；「全部删除」后回退网络加载

## 5. 设置与清理（30s）

- 更多 → 任一设置项 → 设置页
- 图片缓存/下载占用显示；清理后归零

## 演示时主动交代的边界

- 只有 MangaDex 一个内置源（不支持扩展安装）
- 追踪器、备份恢复、本地导入尚未迁移
- 后台下载任务未接系统调度，退到后台可能被挂起
- 未做平板/折叠屏适配
