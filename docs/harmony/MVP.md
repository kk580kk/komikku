# MVP 定义

> 本文件回答一个问题：**第一版能装到手机上、能每天用的最小集合是什么。**

## 一句话定义

用户能在 HarmonyOS 手机上，通过内置 MangaDex 源搜索漫画 → 加入书架 → 在线阅读 → 断网也能看已下载章节。

## 目标用户与场景

| 场景 | 描述 |
|---|---|
| 通勤阅读 | 打开即书架，点开未读章节直接进入阅读器，进度自动保存 |
| 找新书 | 在"浏览"里按 MangaDex 热门/搜索，看到详情后加书架 |
| 离线 | 提前下载若干章节，地铁里无网也能看 |

## P0 用户故事（MVP 验收范围）

| 编号 | 用户故事 | 验收标准 |
|---|---|---|
| US-1 | 打开 App 直接看到书架 | 冷启动 ≤ 1.5s 出首屏；空库显示引导态 |
| US-2 | 书架展示封面/标题/未读角标 | 500 条数据下列表滚动不掉帧（≥55fps） |
| US-3 | 书架可按分类筛选、按标题搜索 | 筛选/搜索 200ms 内出结果 |
| US-4 | 浏览 MangaDex 热门与搜索结果 | 分页加载，翻页不重复、不丢项 |
| US-5 | 查看漫画详情与章节列表 | 章节按话数倒序；已读章节置灰 |
| US-6 | 加入书架/取消收藏 | 操作后书架即时更新（同一会话内） |
| US-7 | 阅读章节（长条模式） | 进入阅读器 ≤ 800ms；退出后记录上次页码；连续阅读 30 分钟不 OOM |
| US-8 | 下载章节并离线阅读 | 下载完成可在飞行模式下打开；失败可重试 |

## 明确不做（MVP 之外）

- 追踪器（MAL / AniList / Kitsu / Shikimori…）
- E-Hentai / NHentai 等其他源（M5）
- 扩展安装（架构上已排除）
- 备份恢复、WebDAV、本地导入（M5）
- 平板 / 折叠屏布局
- 阅读器的双页、横向翻页、Webtoon 之外的复杂模式（M3 之后）
- 多语言（MVP 只出简体中文 + 英文两套资源）

## 成功指标

| 指标 | 目标 |
|---|---|
| 冷启动（中端机） | ≤ 1.5s |
| 书架 500 条滚动 | 平均帧率 ≥ 55fps，无白块 |
| 阅读 30 分钟 | 峰值内存 ≤ 300MB，无 OOM |
| 章节下载成功率 | ≥ 98%（网络正常） |
| 崩溃率 | < 0.5% 会话 |

## MVP 与里程碑的对应

| 里程碑 | 覆盖的用户故事 |
|---|---|
| M1 数据层 | US-1、US-2、US-3（数据部分） |
| M2 图源与浏览 | US-3、US-4、US-5、US-6 |
| M3 阅读器 | US-7 |
| M4 下载 | US-8 |
| M5 打磨 | 全部指标达标 |

> MVP 的完成判定 = M1～M4 全部 DoD 通过 + 上表指标在真机达标。
