## 顺序与依赖

```
M0 ✅ → M1 → M2 → M3 → M4 → M5
              ↘ M3-1（图片管线）可并行
```

- M2 的 `Http` 是 M3 图片下载、M4 下载的前置
- M5-1 依赖 M2 的 Cookie 能力，可提前在 `Http` 里预留
- 每完成一个 M，打 tag：`harmony-v0.1.0` … `harmony-v0.5.0`
