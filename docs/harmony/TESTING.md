# 手工测试清单

> 每个里程碑结束前跑一遍；通过后在 ROADMAP 对应 DoD 勾选。真机或模拟器均可。

## 环境

- DevEco Studio 26.0.0，签名已配置（`File > Project Structure > Signing Configs` → 自动签名）
- 设备：HarmonyOS 手机或模拟器（API 26）

## M1 · 数据层

| # | 用例 | 步骤 | 期望 |
|---|---|---|---|
| M1-1 | 首启种子 | 全新安装 → 打开 | 书架出现 6 本，角标分别为 3 / 0 / 12 / 1 / 5 / 0 |
| M1-2 | 持久化 | 打开后杀进程 → 再启动 | 仍为 6 本，种子不重复插入 |
| M1-3 | 搜索命中 | 搜索框输入「芙莉莲」 | 只剩 1 本 |
| M1-4 | 搜索清空 | 删除关键字 | 恢复 6 本 |
| M1-5 | 详情加载 | 点任一封面 | 标题/作者/简介/20 个章节；章节按话数倒序 |
| M1-6 | 未读状态 | 看详情后返回书架 | 角标数量与详情里未读章节数一致 |
| M1-7 | 移出书架 | 详情页点「移出书架」→ 返回 | 书架少一本，计数 -1 |
| M1-8 | 加入书架 | 详情页点「加入书架」→ 返回 | 书架恢复，顺序按 `last_update` 排 |
| M1-9 | 空态 | 搜索一个不存在的词 | 显示「书架还是空的」引导，不崩溃 |
| M1-10 | 冷启动耗时 | 计时从点击图标到书架出现 | ≤ 1.5s（中端机） |

### 检查数据库（可选，需 hdc）

```bash
hdc shell "find /data/app/el2/100/database/app.komikku.harmony -name '*.db'"
hdc file recv <上一步路径> ./komikku.db
sqlite3 ./komikku.db "select _id,title,favorite from mangas;"
```
